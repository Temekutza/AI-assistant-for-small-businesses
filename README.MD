# Альфа-Помощник: AI-Ассистент для Малого Бизнеса
## Описание

Этот проект разработан в рамках хакатона "Альфа-Будущее Хакатон" от Альфа-Банка и Changellenge. Задача хакатона — создать приложение-помощник, которое использует возможности LLM для автоматизации ключевых задач владельцев малого бизнеса. Платформа анализирует существующие задачи бизнеса, помогает в их решении и предоставляет рекомендации, помогая предпринимателям экономить время и повышать качество управленческих решений.

**Альфа-Помощник** — это разговорный AI-ассистент, встроенный в Telegram-бота и веб-приложение. Он решает повседневные проблемы микробизнеса: отвечает на юридические, маркетинговые и финансовые вопросы, генерирует документы, предлагает шаблоны и чек-листы, анализирует операционные данные (продажи, остатки, платежи) и рекомендует следующие шаги. Решение ориентировано на мобильные сценарии, простоту и интеграцию с экосистемой банка.

Проект учитывает боли целевой аудитории (владельцы кофеен, салонов красоты и т.д.), выявленные через анализ открытых источников. Мы выбрали модель Qwen3:30b за её баланс производительности и открытости, а также интегрировали RAG для работы с данными из CSV-файлов.

## Функции

- **Чат-ассистент в Telegram**: Обработка запросов пользователей, поиск релевантного контекста из данных (RAG), генерация ответов через LLM. Поддержка команд /start, /help, /info.
- **Веб-приложение (FastAPI)**: Интерфейс для чата с ассистентом, страницы с описанием функций, примерами и возможностями.
- **Анализ данных**: Автоматическая загрузка и поиск по CSV-файлам из папки `data/` (продажи, платежи, остатки).
- **Рекомендации**: Краткие, по делу ответы по юридическим вопросам, маркетингу, финансам, управлению. Использует контекст из базы данных.
- **Кэширование**: Двухуровневый кэш (память + SQLite) для ускорения поиска.
- **Логирование**: Полное логирование запросов и ошибок в консоль и файл `bot.log`.

## Технологии

- **Backend**: Python 3.10+, FastAPI (API), aiogram (Telegram-бот)
- **LLM**: Ollama с моделью Qwen3:30b
- **RAG**: LangChain, ChromaDB (векторная БД), OllamaEmbeddings
- **Утилиты**: python-dotenv, cachetools, sqlite3
- **Деплой**: Поддержка Docker (рекомендуется для хакатона), Uvicorn для запуска

Полный список зависимостей в `requirements.txt`.

## Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/alpha-hackaton.git
   cd alpha-hackaton
   ```

2. Создайте виртуальное окружение:
   ```
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # или venv\Scripts\activate на Windows
   ```

3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

4. Настройте `.env` файл (скопируйте `config.env.example` в `config.env` и заполните):
   - `TELEGRAM_BOT_TOKEN`: Токен вашего Telegram-бота
   - `LLM_MODEL`: "qwen3:30b" (по умолчанию)
   - `EMBEDDING_MODEL`: "nomic-embed-text" (по умолчанию)
   - `CHROMA_DB_PATH`: "./chroma_db" (путь к векторной БД)

5. Установите Ollama и модель Qwen3:30b:
   - Скачайте Ollama: https://ollama.ai/
   - Запустите: `ollama run qwen3:30b`

6. Подготовьте данные: Поместите CSV-файлы в папку `data/` (автоматическая загрузка в RAG при первом запуске).

## Запуск

- Локально:
  ```
  python -m src.main
  ```
  - Telegram-бот: Запустится автоматически.
  - Веб-приложение: Доступно по `http://localhost:8000` (страницы: /, /features, /examples, /assistant).

- В Docker (рекомендуется для хакатона):
  1. Соберите образ:
     ```
     docker build -t alpha-pomoshnik .
     ```
  2. Запустите:
     ```
     docker run -p 8000:8000 --env-file config.env alpha-pomoshnik
     ```
  - README с инструкцией по запуску в репозитории.

Для тестирования: Отправьте запрос в Telegram-бот или веб-чат, например: "Как составить договор с поставщиком?"

## Структура Проекта

```
alpha_hackaton/
├── src/
│   ├── api.py              # FastAPI: веб-сервер, API для чата
│   ├── bot.py              # Telegram-бот: обработчики, интеграция с RAG/LLM
│   ├── cache.py            # Кэширование поиска (L1/L2)
│   ├── llm.py              # LLM-сервис: генерация ответов через Ollama
│   ├── logging_config.py   # Настройка логирования
│   ├── main.py             # Запуск: бот + API асинхронно
│   ├── rag.py              # RAG: загрузка CSV, векторная БД, поиск
│   └── frontend/
│       └── static/         # HTML/CSS для веб-приложения
├── data/                   # CSV-файлы для RAG
├── chroma_db/              # Векторная БД (генерируется автоматически)
├── config.env.example      # Шаблон .env
├── requirements.txt        # Зависимости
├── bot.log                 # Логи (генерируется)
└── README.md               # Этот файл
```

## Деплой и Масштабирование

- **Локальный запуск**: Как указано выше.
- **Удалённый сервер**: Рекомендуем Vercel/Render для фронта, Fly.io/Koyeb для бэка. Разверните через Docker-образ.
- **Масштабирование**: Архитектура serverless-ready (FastAPI + asyncio), поддержка горизонтального скейлинга. RAG на ChromaDB легко мигрирует в кластер.
- **Интеграции**: Готово к интеграции с экосистемой Альфа-Банка (API для данных, аутентификация).

Проект соответствует критериям хакатона: стабильность, точность ответов, интуитивный UX (Telegram/веб), бизнес-ценность (решение болей микробизнеса), масштабируемость.
